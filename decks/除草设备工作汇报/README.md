## 计算

- `工具/光学计算.py`：915 nm、芯径 155 μm、NA 0.22（M² ≈ 58），平行光 / 后聚焦 / 前聚焦的光斑、焦深、功率密度。**进振镜光束直径按 12 mm 估算**，拿到准直镜焦距后改参数重跑。
- `工具/动态聚焦追迹.py`：B 方案厂家处方逐面光线追迹。1064 nm 下与 Zemax 的镜间空气隙相差 < 0.08 mm；换成 915 nm（Sellmeier 折射率）后行程 7.94 mm。
- `动图源/原理_动态聚焦.js` 导出 `工具/动态聚焦_真实镜组光斑.json`：各距离光斑和功率密度（厚透镜 ABCD + M² 高斯光束），第 13 页的数字来自这里。

## 动图

```bash
cd decks/除草设备工作汇报/动图源 && npm install
```

```bash
for f in 光路_三种对比.js 原理_*.js; do node render.js "$f" ../assets/动图; done
```

```bash
node render3d.js 振镜三维.html ../assets/动图 振镜扫描_三维
```

几何关系：反射偏转 2θ；F-θ 落点 = f × 偏转角；前聚焦焦点在以振镜为圆心的圆弧上；准直 / 聚焦按傍轴成像；动态聚焦按真实面形 Snell 折射；三维振镜动画先定茎部坐标，再用牛顿迭代反求两镜转角；Z 轴测距 H = L·cosβ 闭环。
